# Translit Keyboard

![Translit Keyboard](docs/banner.png)

**Печатай по-русски — получай латиницу.** Android-клавиатура, которая превращает
«привет» в `privet`, исправляет опечатки, подсказывает слова и переводит на 32 языка —
в том числе прямо на телефоне, без интернета.

Сделано с любовью к деталям: четыре раскладки, обратный транслит, исправление раскладки, автоисправление и подсказки как в больших
клавиатурах, жесты, темы и полный контроль над каждым пикселем клавиши.

## Возможности

- **4 раскладки**, переключение клавишей 🌐 (долгое нажатие на 🌐 или пробел — выбор системной клавиатуры):
  - **Транслит** — русская раскладка, в текст попадает латиница (`привет` → `privet`)
  - **Русская** — обычная кириллица
  - **Обратный транслит** — печатаете латиницей, получаете кириллицу: `privet, kak dela` → «привет, как дела».
    Неоднозначное (`ts` — «ц» или «тс», `e` — «е» или «э», `den` — «день») решает словарь;
    другие прочтения — в подсказках, последняя подсказка оставляет латиницу как набрана (`iPhone`)
  - **QWERTY** — английская клавиатура
  - Какие раскладки перебирает 🌐 — выбирается в настройках; раскладка **запоминается для каждого приложения**
    (в мессенджере — транслит, в почте — английская)
  - Русские буквы — **ЙЦУКЕН** или фонетическая **ЯВЕРТЫ** (я — q, в — w, ч — h)
- **Пять систем транслитерации** (переключаются в настройках, подпись на пробеле показывает текущую):
  - Разговорная: `й→y, ц→c, х→h, щ→sch` — «привет» → `privet`
  - Паспортная ICAO: `й→i, ц→ts, х→kh, щ→shch` — как в загранпаспорте
  - ГОСТ 7.79-2000 (система Б): `й→j`, `х→x`, `щ→shh`, `ц→cz`, а перед «и», «е», «ы»… — `c`:
    «цирк» → `cirk`, «царь» → ``czar` ``
  - BGN/PCGN: «Елена» → `Yelena`, «Фёдор» → `Fyodor`, «Ильич» → `Ilyich`, «подъезд» → `podyezd`
  - Своя таблица: латиница для каждой буквы задаётся в настройках
  - Регистр как в большой клавиатуре: «Женя» → `Zhenya`, с Caps Lock «ЖЕНЯ» → `ZHENYA`
- **Исправление раскладки**: `ghbdtn` → «привет», `руддщ` → `hello` — по пробелу, и раскладка
  сама переключается на нужный язык. ⌫ сразу после замены возвращает набранное и прежнюю раскладку
  (слово запоминается и больше не исправляется). Короткие и сомнительные слова — только подсказкой.
- **Действия с выделенным текстом** (подсказки над клавиатурой): → латиница, → кириллица,
  ⇄ раскладка (`ghbdtn? rfr ltkf&` → «привет, как дела?»), → ссылка («Привет, мир!» → `privet-mir`)
- **Автоисправление как в больших клавиатурах**: словари на ~48 тыс. слов для русского и английского,
  учёт соседних клавиш и частых ошибок (`превет` → `привет`, `сегодя` → `сегодня`, `teh` → `the`,
  `dont` → `don't`, `i` → `I`, `вобщем` → `в общем`). Настоящие слова и разговорное («спс», «норм», `thx`)
  не трогаются.
  - **⌫ сразу после исправления** возвращает набранное слово — и клавиатура его запоминает
  - Слова с заглавной посреди фразы (имена) и набранные КАПСОМ исправляются осторожнее или не исправляются
- **Подсказки**: исправление (выделено), продолжения слова, следующее слово после пробела
  («спасибо» → «пожалуйста»); первая подсказка в «кавычках» — оставить как набрано.
- **Обучение на устройстве**: клавиатура запоминает ваши слова и пары слов (файл в памяти приложения,
  никуда не отправляется). Можно отключить или стереть в настройках.
- **Удобства ввода**: заглавная в начале предложения, точка двойным пробелом, «привет ,» → «привет, »
  после подсказки, правильные апострофы и дефисы (`don't`, «кто-то»).
- **Жесты**: свайп по пробелу — двигать курсор; свайп влево с ⌫ — выделить и удалить слова;
  удержание ⌫ — сначала по букве, потом по словам; двойное нажатие ⇧ — Caps Lock.
- **Поля ввода**: в паролях — без подсказок и обучения; для email/URL — `@` и `.com` на нижнем ряду;
  для чисел и телефонов — цифровая клавиатура; кнопка Enter показывает действие поля (найти, отправить, далее, готово).
- **Символы и эмодзи**: две страницы символов, панель эмодзи, долгое нажатие с выбором скольжением
  (е→ё, ь→ъ, верхний ряд → цифры, -→—–•, $→₽€£ и т.д.); эмодзи с тоном кожи и флаги стираются целиком.
- **Backspace по блокам**: «щ» → `sch` стирается одним нажатием
- **Перевод прямо в клавиатуре** (значок 文A над клавишами, в любом текстовом поле и в любой раскладке):
  - **Набор с переводом** — «пишу по-русски, отправляю по-английски»: текст набирается в строке панели
    (с подсказками и автоисправлением), а в поле сразу появляется перевод. ⏎ оставляет перевод и начинает
    следующее сообщение, второй ⏎ — отправить. Язык — кнопка «Русский → English ▾» (32 языка)
  - **Выделенное, поле, скопированное**: подсказка «🌐 перевести» у выделенного текста, кнопки «Поле» и «Буфер»;
    только что скопированный текст клавиатура предлагает перевести сама («📋 перевести скопированное»).
    Своё — на выбранный язык, чужое — на русский; «Заменить», «Вставить» или «Копировать»
  - Транслит в поле (`privet, kak dela`) сначала становится кириллицей, а английский текст остаётся английским —
    это решают словари (и ML Kit)
  - **Без интернета** — Google ML Kit на телефоне: язык скачивается один раз (~30 МБ, по умолчанию только по Wi‑Fi),
    дальше текст никуда не уходит. Режимы: «Авто» (на телефоне, если языки скачаны, иначе онлайн),
    «Только без интернета», «Только онлайн». Онлайн — Google Translate с резервным MyMemory
- **Полная кастомизация**: тёмная/светлая тема, 6 цветов акцента, высота клавиш,
  размер шрифта, вибрация, звук нажатия

## Сборка

Нужны: JDK 17+ и Android SDK (platform 35, build-tools 35).

```bash
# укажите путь к SDK в local.properties (sdk.dir=/path/to/android-sdk)
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk` (~20 МБ: перевод без интернета — это
библиотеки ML Kit для arm64-v8a и armeabi-v7a; эмуляторы x86 не поддерживаются).

Лёгкая сборка без ML Kit (~3 МБ, перевод только онлайн, подойдёт и для эмулятора x86):

```bash
./gradlew assembleDebug -Plite
```

## Установка и активация через adb

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell ime enable com.example.translit/.TranslitKeyboardService
adb shell ime set com.example.translit/.TranslitKeyboardService
```

Или вручную: приложение «Translit Keyboard» → кнопки 1 и 2 на главном экране
(включить в настройках → выбрать как текущую клавиатуру).

## Тесты

```bash
./gradlew testDebugUnitTest                 # ввод, автозамена, транслит, раскладки, словари, окно, перевод
./gradlew testDebugUnitTest -Pscreenshots   # + скриншоты клавиатуры в app/build/screenshots
```

Тесты окна клавиатуры используют Robolectric: при первом запуске Gradle скачает его Android-библиотеки.

├── PopupOverlay.kt             — увеличенная клавиша и панель вариантов
├── SuggestionStrip.kt          — панель подсказок
├── TranslationManager.kt       — перевод: на телефоне или онлайн (Google, MyMemory), язык текста, кэш

├── LiveTranslation.kt          — набор с переводом: строка набора → перевод в поле, ⏎, новое сообщение
├── TranslatePanel.kt           — панель перевода: набор, результат, выбор языка
├── TextBuffer.kt               — поле ввода в памяти (строка набора панели перевода и тесты)

└── MainActivity.kt             — экран настроек и активации
app/src/mlkit/…/OfflineEngines.kt — перевод на телефоне через Google ML Kit (обычная сборка)

## Кастомные раскладки

Положите JSON-файл в `filesDir/layouts/` (например, через `adb push`):

```json
{
  "id": "code",
  "name": "Программист",
  "rows": [
    [{"k": "q", "lp": ["Q"]}, {"k": "w"}, {"k": "e"}, {"k": "r"}, {"k": "t"}, {"k": "y"}],
    [{"k": "a"}, {"k": "s"}, {"k": "d"}, {"k": "f"}, {"k": "g"}, {"k": "h"}],
    [{"k": "z"}, {"k": "x"}, {"k": "c"}, {"k": "v"}, {"k": "b"}, {"k": "n"}, {"k": "m"}]
  ]
}
```

`k` — символ клавиши, `lp` — варианты при долгом нажатии. Раскладка появится в
цикле переключения 🌐 после ЙЦУКЕН.

## Словари

Встроенные словари `app/src/main/assets/dict/{ru,en}.tsv` собираются скриптом
`python3 tools/build_dicts.py` из частотных списков
[FrequencyWords](https://github.com/hermitdave/FrequencyWords) (© Hermit Dave, OpenSubtitles 2018,
CC BY-SA 4.0) — подробности в [assets/dict/LICENSE.txt](app/src/main/assets/dict/LICENSE.txt).
Частые опечатки, которые не исправить одной правкой, — в `{ru,en}.fixes.tsv`.

Словари-плагины: файлы `filesDir/dictionaries/*.txt` — по одному слову в строке. Слова попадают
в подсказки и не исправляются. Удобно для IT-терминов, медицинских слов и т.п. Слова из
системного пользовательского словаря Android тоже учитываются.

## Перевод

32 языка; без интернета — все, кроме казахского, азербайджанского и узбекского (их нет в ML Kit).
Куда уходит текст:

| Режим | Языки скачаны | Языки не скачаны |
|---|---|---|
| Авто | переводит телефон | Google Translate (резерв — MyMemory), панель предложит скачать языки |
| Только без интернета | переводит телефон | ничего не отправляется, панель просит скачать языки |
| Только онлайн | Google Translate (резерв — MyMemory) | то же |

Языки скачиваются и удаляются в настройках («Языки для перевода без интернета») или кнопкой «Скачать»
на панели. Английский встроен; перевод идёт через английский, поэтому для «русский → немецкий» нужны оба языка.
Определение языка текста — тоже на телефоне (ML Kit), а в lite-сборке — по буквам.

Результаты кэшируются (в памяти и на диске) — повторный перевод того же текста на тот же язык
происходит мгновенно, без сети. Переводы из набора с переводом на диск не пишутся.

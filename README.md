# Translit Keyboard

![Translit Keyboard](docs/banner.png)

**Печатай по-русски — получай латиницу.** Android-клавиатура, которая превращает
«привет» в `privet`, исправляет опечатки, подсказывает слова и переводит на 32 языка.

Сделано с любовью к деталям: три раскладки, автоисправление и подсказки как в больших
клавиатурах, жесты, темы и полный контроль над каждым пикселем клавиши.

## Возможности

- **3 раскладки**, переключение клавишей 🌐 (долгое нажатие на 🌐 или пробел — выбор системной клавиатуры):
  - **Транслит** — русская раскладка ЙЦУКЕН, в текст попадает латиница (`привет` → `privet`)
  - **ЙЦУКЕН** — обычная русская клавиатура
  - **QWERTY** — английская клавиатура
- **Две таблицы транслитерации** (переключаются в настройках):
  - Разговорная: `й→y, ц→c, х→h, щ→sch` — «привет» → `privet`
  - Паспортная ICAO: `й→i, ц→ts, х→kh, щ→shch` — как в загранпаспорте
  - Регистр как в большой клавиатуре: «Женя» → `Zhenya`, с Caps Lock «ЖЕНЯ» → `ZHENYA`
- **Автоисправление как в больших клавиатурах**: словари на ~48 тыс. слов для русского и английского,
  учёт соседних клавиш и частых ошибок (`превет` → `привет`, `сегодя` → `сегодня`, `teh` → `the`,
  `dont` → `don't`, `i` → `I`, `вобщем` → `в общем`). Настоящие слова и разговорное («спс», «норм», `thx`)
  не трогаются.
  - **⌫ сразу после исправления** возвращает набранное слово — и клавиатура его запоминает
  - Слова с заглавной посреди фразы (имена) и набранные КАПСОМ исправляются осторожнее или не исправляются
- **Подсказки**: исправление (выделено), продолжения слова, следующее слово после пробела
  («спасибо» → «пожалуйста»); первая подсказка в «кавычках» — оставить как набрано.
- **Обучение на устройстве**: клавиатура запоминает ваши слова и пары слов (файл в памяти приложения,
  никуда не отправляется). Можно отключить или стереть в настройках.
- **Удобства ввода**: заглавная в начале предложения, точка двойным пробелом, «привет ,» → «привет, »
  после подсказки, правильные апострофы и дефисы (`don't`, «кто-то»).
- **Жесты**: свайп по пробелу — двигать курсор; свайп влево с ⌫ — выделить и удалить слова;
  удержание ⌫ — сначала по букве, потом по словам; двойное нажатие ⇧ — Caps Lock.
- **Поля ввода**: в паролях — без подсказок и обучения; для email/URL — `@` и `.com` на нижнем ряду;
  для чисел и телефонов — цифровая клавиатура; кнопка Enter показывает действие поля (найти, отправить, далее, готово).
- **Символы и эмодзи**: две страницы символов, панель эмодзи, долгое нажатие с выбором скольжением
  (е→ё, ь→ъ, верхний ряд → цифры, -→—–•, $→₽€£ и т.д.); эмодзи с тоном кожи и флаги стираются целиком.
- **Backspace по блокам**: «щ» → `sch` стирается одним нажатием
- **Переводчик** (кнопка над клавиатурой, для ЙЦУКЕН и QWERTY): набираете текст, выбираете один из 32 языков,
  кнопка «⤵ Вставить перевод» заменяет исходный текст. Google Translate с резервным MyMemory API.
- **Полная кастомизация**: тёмная/светлая тема, 6 цветов акцента, высота клавиш,
  размер шрифта, вибрация, звук нажатия

## Сборка

Нужны: JDK 17+ и Android SDK (platform 35, build-tools 35).

```bash
# укажите путь к SDK в local.properties (sdk.dir=/path/to/android-sdk)
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Установка и активация через adb

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell ime enable com.example.translit/.TranslitKeyboardService
adb shell ime set com.example.translit/.TranslitKeyboardService
```

Или вручную: приложение «Translit Keyboard» → кнопки 1 и 2 на главном экране
(включить в настройках → выбрать как текущую клавиатуру).

## Тесты

```bash
./gradlew testDebugUnitTest                 # логика ввода, автозамена, транслит, словари, высота окна
./gradlew testDebugUnitTest -Pscreenshots   # + скриншоты клавиатуры в app/build/screenshots
```

Тесты окна клавиатуры используют Robolectric: при первом запуске Gradle скачает его Android-библиотеки.

## Структура

```
app/src/main/java/com/example/translit/
├── TranslitKeyboardService.kt  — InputMethodService: поля ввода, раскладки, звук/вибрация, перевод
├── InputEngine.kt              — логика набора: composing, автозамена и её отмена, регистр, пробел/⌫/Enter
├── SuggestionEngine.kt         — исправления, продолжения, следующее слово, пользовательские словари
├── WordDictionary.kt           — компактный частотный словарь (assets/dict/*.tsv)
├── UserHistory.kt              — обучение на устройстве (слова и пары слов)
├── TranslitMode.kt             — таблицы транслитерации (разговорная / ICAO)
├── KeyboardView.kt             — отрисовка клавиш и жесты (мультитач, свайпы, долгое нажатие)
├── KeyboardModels.kt           — сборка рядов клавиш для букв, символов, эмодзи, цифр
├── KeyboardLayoutManager.kt    — раскладки, варианты долгого нажатия, кастомные раскладки
├── PopupOverlay.kt             — увеличенная клавиша и панель вариантов
├── SuggestionStrip.kt          — панель подсказок
├── TranslationManager.kt       — Google Translate + MyMemory, кэш
├── KbSettings.kt               — настройки, темы/палитры
└── MainActivity.kt             — экран настроек и активации
app/src/main/assets/dict/       — словари ru/en и таблицы частых опечаток
tools/build_dicts.py            — сборка словарей из частотных списков FrequencyWords
```

## Кастомные раскладки

Положите JSON-файл в `filesDir/layouts/` (например, через `adb push`):

```json
{
  "id": "code",
  "name": "Программист",
  "rows": [
    [{"k": "q", "lp": ["Q"]}, {"k": "w"}, {"k": "e"}, {"k": "r"}, {"k": "t"}, {"k": "y"}],
    [{"k": "a"}, {"k": "s"}, {"k": "d"}, {"k": "f"}, {"k": "g"}, {"k": "h"}],
    [{"k": "z"}, {"k": "x"}, {"k": "c"}, {"k": "v"}, {"k": "b"}, {"k": "n"}, {"k": "m"}]
  ]
}
```

`k` — символ клавиши, `lp` — варианты при долгом нажатии. Раскладка появится в
цикле переключения 🌐 после ЙЦУКЕН.

## Словари

Встроенные словари `app/src/main/assets/dict/{ru,en}.tsv` собираются скриптом
`python3 tools/build_dicts.py` из частотных списков
[FrequencyWords](https://github.com/hermitdave/FrequencyWords) (© Hermit Dave, OpenSubtitles 2018,
CC BY-SA 4.0) — подробности в [assets/dict/LICENSE.txt](app/src/main/assets/dict/LICENSE.txt).
Частые опечатки, которые не исправить одной правкой, — в `{ru,en}.fixes.tsv`.

Словари-плагины: файлы `filesDir/dictionaries/*.txt` — по одному слову в строке. Слова попадают
в подсказки и не исправляются. Удобно для IT-терминов, медицинских слов и т.п. Слова из
системного пользовательского словаря Android тоже учитываются.

## Перевод

32 языка. Результаты кэшируются (в памяти и на диске) — повторный перевод
того же текста на тот же язык происходит мгновенно, без сети.
